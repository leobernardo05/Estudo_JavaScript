# 📚 Estudo de JavaScript

Este repositório contém meus estudos práticos de **JavaScript**, desde os fundamentos da linguagem até conceitos mais avançados introduzidos no **ES6** e na **Programação Orientada a Objetos**.

O objetivo deste projeto é consolidar o aprendizado através da criação de diversos exemplos e exercícios práticos, organizados por temas.

---

# 🚀 Conteúdo abordado

O repositório cobre diversos tópicos importantes da linguagem JavaScript:

### 🧠 Fundamentos da linguagem

* Variáveis (`var`, `let`, `const`)
* Tipos de dados
* Casting de tipos
* Operadores
* Estruturas condicionais
* Operador ternário
* Switch
* Estruturas de repetição (`for`, `while`)

---

### 🔁 Arrays

* Criação de arrays
* Percorrendo arrays
* Ordenação de arrays
* Pesquisa em arrays
* Métodos como:

  * `forEach()`
  * `filter()`

---

### ⚡ Funções

* Declaração de funções
* Parâmetros variáveis
* Parâmetros default
* Arrow functions

---

### 🖱 Manipulação do DOM

* Seleção de elementos
* Manipulação de classes
* Manipulação de estilos
* Manipulação de inputs
* Eventos de formulário
* Eventos de mouse
* Eventos de teclado
* Eventos da janela

---

### 🧱 Programação Orientada a Objetos

* Abstração
* Encapsulamento
* Herança
* Polimorfismo
* Prototype
* Prototype chain

---

### ✨ Recursos modernos do JavaScript (ES6+)

* Arrow Functions
* Destructuring
* Template Strings
* Spread Operator
* Rest Operator
* Parâmetros default
* Object Literal Improvements
