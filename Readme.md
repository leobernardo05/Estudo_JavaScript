# 📚 Estudo de JavaScript

Este repositório contém meus estudos práticos de **JavaScript**, desde os fundamentos da linguagem até conceitos avançados de **ES6+, programação orientada a objetos, assincronismo e novas features da linguagem**.

O objetivo é consolidar o aprendizado através de exemplos práticos, exercícios e pequenos projetos organizados por temas.
